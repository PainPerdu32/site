# ACPI Table Dumper for Windows

This script dumps the ACPI tables on a Windows system.

## Prerequisites

You must have the `acpi-view` tool installed. You can find it by searching for "acpi-view" on your favorite search engine. Make sure `acpi-view.exe` is in your system's PATH.

## Usage

1.  Open a command prompt.
2.  Run the `dump_acpi.bat` script.
3.  The ACPI tables will be saved to a file named `acpi.dat`.
